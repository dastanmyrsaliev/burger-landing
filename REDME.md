# Бургер лендинг

Пет-проект: Одностраничный лендинг для заказа бургеров.

## Архитектура

- `images/` - Иконки и картинки.
- `index.html` - Структура HTML-документа.
- `style.css` - Стили для HTML-документа.

## Что используется

- HTML5 и CSS3.
- Семантические тэги.
- Методология БЭМ.
- Flexbox, Grid Layout.

## Как запустить

```bash
git https://github.com/dastanmyrsaliev/burger-landing.git
```

Запустить с помощью расширения LiveServer или запустить файл index.html в браузере.
